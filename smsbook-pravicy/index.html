隐私政策 (Privacy Policy)

发布日期：2026年7月26日 ｜ 生效日期：2026年7月26日

1. 概述

短信记账（以下简称"本应用"）是一款 iOS 原生记账工具，用于将您通过"快捷指令"转发的银行/支付短信自动解析为消费记录（金额、商户、时间），并支持手动记账、图片备注、消费统计与 CSV 导出。本应用是纯本地优先设计：核心记账数据默认只保存在您的设备上，不需要注册账号，也没有我们自己的服务器来接收或存储您的数据。

本隐私政策说明本应用在您使用过程中会处理哪些信息、如何处理，以及您可以做哪些选择。

2. 短信内容的处理方式

本应用没有、也无法申请读取您设备短信收件箱的权限（iOS 系统不允许第三方应用访问系统短信数据库）。短信相关功能的实现方式如下：

  • 您需要自行在系统"快捷指令"App 中创建一个"收到信息时"自动化，选择将短信文本转发给本应用的"记录短信交易"动作。
  • 本应用只能接收到您主动配置转发过来的那一条短信文本，不会、也没有能力主动读取其他任何短信。
  • 收到短信文本后，金额与商户信息的提取全部通过设备本地的正则匹配逻辑完成，不上传短信原文到任何服务器（DeepSeek AI 分类功能除外，见第 3 条，且该功能默认关闭）。
  • 系统会自动判断短信是收入还是支出：识别为收入（如工资到账、转账收入、退款）的短信会被直接忽略，不会生成任何记录。

3. 数据采集与使用

  • 本地存储：您的消费记录（金额、商户、分类、备注、图片、原始短信文本片段）保存在设备本地的数据库中，受 iOS 系统沙盒机制保护，我们没有服务器，因此也无法接触到这些数据。
  • 个人身份信息：本应用不要求注册账号，不收集您的姓名、手机号、电子邮件等身份信息。
  • DeepSeek AI 自动分类（可选，默认关闭）：如果您在"设置 → AI 设置"中主动填入自己的 DeepSeek API Key 并开启此功能，应用会将该笔交易的商户名称、金额以及原始短信文本发送给第三方服务 DeepSeek（platform.deepseek.com / api.deepseek.com）以获取消费分类建议。
    请注意：原始短信文本中可能包含银行名称、卡号后四位等信息，开启此功能后会随请求一并发送给 DeepSeek。如果您不希望短信原文离开本机，请保持"AI 自动分类"关闭 —— 关闭状态下，应用会改用完全离线的本地关键词规则进行分类，不会产生任何网络请求。DeepSeek 对这些数据的处理遵循其自身的隐私政策，与本应用无关。
  • DeepSeek API Key 存储：您填入的 API Key 使用 iOS Keychain 加密保存在设备本地。调用 DeepSeek 接口时，Key 会作为身份验证信息随请求发送给 DeepSeek 官方服务器，这是使用该第三方服务所必需的，除此之外不会被发送到任何其他地方。

4. 第三方服务

本应用不包含任何广告 SDK、用户行为追踪插件或数据分析工具（如 Google Analytics）。唯一涉及的第三方服务是您可自主选择是否开启的 DeepSeek AI 分类（见第 3 条）。我们不会出于营销目的将您的任何数据出售或分享给第三方。

5. 数据安全

  • 本地存储：记账数据与图片保存在设备本地的应用沙盒中，随系统数据保护机制加密。
  • 网络通信：仅在您主动开启 AI 分类功能时才会产生网络请求，且使用 HTTPS 加密传输。
  • 凭证存储：DeepSeek API Key 存储于 iOS Keychain，而非明文保存。

6. 权限说明

为实现相应功能，本应用可能会请求以下权限，均为按需触发，不会在后台静默获取：

  • 快捷指令 / App Intent：用于接收您通过"快捷指令"自动化转发的短信文本，仅在您主动配置该自动化后才会触发。
  • 照片（可选）：用于给某笔消费添加图片备注。使用系统 PhotosPicker 选择器，本应用只能获取您明确选中的那一张图片，不会获得完整相册的访问权限。
  • 通知（可选）：用于在单笔消费金额超过您设定的阈值时提醒您确认或编辑该记录，仅在您开启"大额提醒"后请求。
  • 网络访问（可选）：仅在您开启"AI 自动分类"并触发分类请求时使用，用于连接 DeepSeek 接口。

本应用不会请求短信收件箱、通讯录、定位、麦克风等权限。

7. 数据导出与删除

您可以随时在应用内将全部消费记录导出为 CSV 文件，通过系统分享面板发送到您指定的位置。您也可以随时删除任意一笔记录，或直接删除应用以清除设备本地保存的全部数据；由于我们没有服务器保存您的数据副本，删除操作是不可恢复的。

8. 儿童隐私

本应用不会主动收集任何个人身份信息，也没有专门面向 13 岁以下儿童设计。如果您认为儿童在未经监护人同意的情况下使用了本应用并涉及隐私问题，请通过下方方式联系我们处理。
