AI润色 隐私政策

生效日期 / Effective Date: 2026-08-06

一句话总结：AI润色 不运营任何服务器，不收集、不上传你的任何数据。你在 App 里输入的文字，只会在你自己配置了 AI 服务商之后，从你的设备直接发送给该服务商；开发者本人接触不到这些内容。

1. 我们收集的信息

AI润色 是一个纯本地运行的工具类 App，不收集任何个人身份信息，不设账号系统，不包含广告 SDK 或数据分析 SDK。App 内产生的以下数据，全部只保存在你设备本机的 App 沙盒内，从不上传到开发者或任何第三方服务器：

  • 你自定义的功能组与 Prompt 模板
  • 你的处理历史记录（原文与 AI 生成结果）
  • 你填写的 AI 服务商 API Key（保存在系统钥匙串 Keychain 中，采用系统级加密保护）

卸载 App、或在设置里清空历史记录/恢复默认功能，会一并清除这些本地数据。

2. 第三方 AI 服务商

AI润色 支持你自行配置 OpenAI 兼容接口（例如 DeepSeek、通义千问等）或 Anthropic Claude 接口。当你使用 App 内任意"处理"功能时：

  • 你输入的文字，会由你的设备直接发送给你自己配置的 AI 服务商，用于生成处理结果；
  • 这个过程不经过开发者的任何服务器，开发者无法看到、也不会保存你发送或收到的任何内容；
  • 该服务商如何处理、存储你发送的数据，受该服务商自己的隐私政策约束，与本政策无关。请在使用前查阅你所选服务商（如 OpenAI、Anthropic、DeepSeek 等）各自公开的隐私政策。

3. 快捷指令与 Siri

如果你在"快捷指令"App 或 Siri 中使用 AI润色 提供的操作，处理流程与上述一致：文本同样是从你的设备直接发送给你配置的 AI 服务商，开发者不会经手。

4. 数据安全

API Key 存储在 iOS 系统的 Keychain 中，受系统级加密与访问控制保护。App 内其他数据（功能配置、历史记录）存储在 App 私有的沙盒目录内，其他 App 无法访问。

5. 儿童隐私

AI润色 不面向 13 周岁以下儿童，也不会主动收集儿童的个人信息。

6. 政策变更

如果本政策有实质性更新，我们会在此页面更新"生效日期"并说明变更内容。建议你在更新 App 后回顾一下本页面。

English Summary

AI翻译与润色 ("the App") does not operate any backend server and does not collect, transmit, or sell any personal data. All data created by using the App — your custom prompt templates, your processing history, and the API key you enter — is stored only locally on your device (settings/history in the app's private sandbox, API key in the iOS Keychain). When you use any processing feature, the text you provide is sent directly from your device to the AI provider (OpenAI-compatible endpoint or Anthropic) that you personally configure with your own API key — this never passes through any server operated by the developer. That provider's handling of your data is governed by its own privacy policy, not this one. The App contains no analytics SDKs, no advertising SDKs, and no account system.
